# ภาพรวมการทำงานของโปรเจค

โปรเจคนี้เป็นเว็บแอปพลิเคชันที่พัฒนาด้วย .NET (C#) โดยใช้โครงสร้างแบบ Razor Pages สำหรับการสร้างหน้าเว็บแบบไดนามิก โครงสร้างไฟล์หลักประกอบด้วย:

- `Program.cs` : จุดเริ่มต้นของแอปพลิเคชัน กำหนดการตั้งค่าและเริ่มต้น Web Host
- `Options.cs` : สำหรับจัดการ options หรือ configuration ต่าง ๆ ของระบบ
- `appsettings.json` : ไฟล์สำหรับเก็บค่าคอนฟิก เช่น การเชื่อมต่อฐานข้อมูล หรือค่าต่าง ๆ ที่ใช้ในระบบ
- `Web.csproj` : ไฟล์โปรเจคของ .NET สำหรับกำหนด dependencies และการ build
- `Web.sln` : ไฟล์ solution สำหรับ Visual Studio
- `Pages/` : โฟลเดอร์เก็บ Razor Pages เช่น `Index.cshtml` (หน้าแรก) และ `Index.cshtml.cs` (โค้ดเบื้องหลังของหน้าแรก)
- `web.zip` : ไฟล์บีบอัดที่อาจใช้สำหรับ deploy หรือสำรองข้อมูล

## การทำงานโดยรวม

1. เมื่อรันโปรเจค แอปพลิเคชันจะเริ่มต้นจาก `Program.cs` เพื่อสร้างและตั้งค่า Web Host
2. โหลดค่าคอนฟิกจาก `appsettings.json` และ options อื่น ๆ ผ่าน `Options.cs`
3. เมื่อผู้ใช้เข้าถึงเว็บเพจ เช่น หน้าแรก (`Index.cshtml`), ระบบจะประมวลผลโค้ดใน `Index.cshtml.cs` เพื่อเตรียมข้อมูลและแสดงผลผ่าน Razor Page
4. สามารถปรับแต่งค่าต่าง ๆ ได้ผ่านไฟล์คอนฟิกและ options

## เทคโนโลยีที่ใช้
- .NET (C#)
- Razor Pages
- JSON สำหรับคอนฟิก

## การ deploy
สามารถนำไฟล์ `web.zip` ไปใช้สำหรับการ deploy ขึ้น production หรือ server อื่น ๆ ได้
